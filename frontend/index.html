🔢 Kalkulator kebutuhan produksi

Simulasikan jumlah loyang sebelum dicatat. Setiap loyang menggunakan 2 pcs untuk masing-masing jenis kemasan dan kertas minyak.

Masukkan jumlah loyang untuk melihat estimasi pemakaian.

Catat barang masuk

Total barang dihitung otomatis: (jumlah pack × isi per pack) + tambahan pcs. Contoh: 2 pack × 100 pcs + 5 pcs = 205 pcs.

Catat target produksi

Pilih outlet, lalu isi jumlah setiap varian. Total seluruh loyang dihitung otomatis dan ditampilkan sebelum target disimpan.

Centang hanya varian yang kemasannya ingin diatur khusus. Varian yang tidak dicentang tetap memakai hitungan normal.

Setiap varian memiliki jumlah kemasan sendiri. Kertas minyak dan kedua jenis Box isi 5 otomatis mengikuti jumlah Box isi 5.

Laporan Target & Stok Harian

Buat laporan otomatis berisi target setiap outlet, jumlah per varian, stok sebelumnya, pemakaian kemasan, stok akhir, dan pengurangan di luar target.

Pilih tanggal mana pun yang ingin dibuat ulang. Isi laporan dihitung berdasarkan riwayat pada tanggal tersebut.

Laporan otomatis dibuat setelah pukul 18.00 WIB saat aplikasi aktif. Anda juga dapat menekan Buat Laporan Harian kapan saja.

Riwayat transaksi

Abon Gulung Gembul Laporan · Operasional & Stok

Aplikasi operasional Abon Gulung Gembul untuk mengelola persediaan kemasan, target produksi, laporan harian, musik lokal, dan pencadangan data offline.

Versi 3.0.0
Pengembang

Dirancang dan dikembangkan oleh KatsuCode bersama Insan untuk mendukung operasional Abon Gulung Gembul.

Fitur aplikasi

📦 Manajemen stok & batas minimum

Pantau persediaan lima jenis kemasan dalam satu dashboard dan atur batas minimum agar stok kritis lebih mudah dikenali.

🚚 Barang masuk

Catat penerimaan barang berdasarkan pack, isi per pack, dan tambahan satuan.

🎯 Target produksi per outlet

Catat Ori, Beef, Spicy, dan Cheese untuk Grand Wisata, Bektim, atau Harapan Indah. Atur kebutuhan Box isi 3 dan Box isi 5 secara khusus per varian, lalu edit target tanpa membuat transaksi ganda.

📊 Laporan harian otomatis

Susun target per outlet, varian, stok sebelumnya, pemakaian, stok akhir, dan pengurangan di luar target. Laporan dibuat setelah pukul 18.00 WIB saat aplikasi aktif atau dibuka kembali, lalu disimpan sebagai TXT.

🧾 Riwayat & koreksi transaksi

Telusuri transaksi, revisi jumlah pengurangan, kembalikan sebagian stok, atau batalkan pengurangan dengan alasan dan jejak audit.

✍️ Pengurangan stok manual

Catat barang rusak, hilang, atau pemakaian di luar produksi dengan alasan wajib dan kontrol hak akses.

👥 Manajemen akun bertingkat

Admin dapat membuat akun dengan username, password, dan peran Admin atau Karyawan. Password disimpan dalam bentuk hash di server.

🧮 Estimasi kapasitas produksi

Perkirakan jumlah loyang yang dapat diproduksi berdasarkan ketersediaan kemasan utama, tanpa mengubah stok.

🔄 Update langsung dari aplikasi

Admin dapat memeriksa commit branch main dan menerapkan pembaruan tanpa mengetik perintah Git di Termux. Antrean transaksi harus disinkronkan terlebih dahulu.

🛡️ Cadangkan & pulihkan database

Buat file .insanbackup ber-checksum dan pulihkan database setelah validasi. Server membuat salinan kondisi sebelum pemulihan.

📡 Multi-perangkat & offline-first

Satu HP menjalankan server pusat; perangkat lain mengakses lewat jaringan lokal. Catatan offline masuk antrean dan dikirim saat koneksi pulih.

📈 Analitik & kalender produksi

Sediakan ringkasan pemakaian stok berdasarkan periode dan kalender target produksi bulanan.

📤 Ekspor transaksi

Unduh riwayat transaksi dalam format CSV untuk pengolahan dan arsip lebih lanjut.

♫ Pemutar musik lokal

Antrean pemutaran, daftar putar, pencarian, acak, mode ulangi, seek native, kontrol notifikasi Android, dan impor banyak file. File asli tetap aman saat entri aplikasi dihapus.

▣ Backup QR offline

Snapshot QR otomatis mengikuti perubahan stok, target, transaksi, dan antrean. Mendukung QR multi-bagian, pemindaian kamera, pemilihan gambar dari galeri, serta validasi SHA-256 sebelum pemulihan lokal.

⚡ Input responsif

Transaksi disimpan lebih dahulu ke penyimpanan lokal, lalu sinkronisasi server berjalan di latar belakang. Laporan dihitung dari data lokal tanpa menunggu permintaan jaringan.

Keunggulan

  • Offline-first: tetap dapat melihat data tersimpan dan mencatat perubahan saat koneksi terputus.
  • Sinkronisasi otomatis: antrean transaksi dikirim ke server saat perangkat kembali online.
  • Data lokal: backend berjalan di Termux dan menyimpan database pada perangkat server.
  • Ringan: menggunakan Node.js, Express, dan frontend web tanpa bergantung pada layanan cloud berbayar.
  • Tampilan adaptif: mendukung tema terang serta tema gelap monokrom hitam-putih dan navigasi yang ramah perangkat seluler.
  • Hak akses: Admin mengelola akun dan pengaturan penting; Karyawan menggunakan fitur operasional sesuai izin server.
  • Loading koneksi: layar pembuka memeriksa server dan menampilkan status saat aplikasi beralih ke data lokal/offline.
  • Arsip laporan: aplikasi Android menyimpan laporan di Download/Abon Gulung Gembul dengan nama tanggal-bulan-tahun; laporan tanggal sama diperbarui.
  • Kontrol data: backup memiliki checksum SHA-256, pemulihan divalidasi, dan server menyimpan salinan sebelum restore.
  • Jejak audit: aktivitas penting dan koreksi stok dicatat untuk membantu penelusuran.
